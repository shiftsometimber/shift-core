# Shift proactive delivery thresholds

Proactivity should feel useful, not needy.

- Only durable relationship intelligence can generate proactive delivery candidates.
- Confidence must be at least 0.80 for member-facing delivery.
- Default cooldown is 48 hours between proactive prompts, configurable 12–168 hours.
- Never proactively deliver crisis, diagnosis, medication-change, exact symptom or other sensitive inference.
- Prefer one high-value prompt over a stack of nudges.
- Member can disable automatic memory and proactive insights independently.
- Current-message safety always overrides proactive behaviour.
