# Shift AI Hyperdrive Pack V2

This pass completes three commissioning items:

1. Shoulder gear now changes the generation prompt itself rather than being applied only as response metadata.
2. Proactive insights require >=0.80 confidence and obey a configurable delivery cooldown (default 48h, range 12–168h).
3. Members can inspect/update memory privacy settings, disable automatic memory, disable proactive insights, and delete an individual learned memory.

The goal is useful initiative without nagging, and memory that feels consensual rather than creepy.
