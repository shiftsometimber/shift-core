# Shift industrial content objectives

## Scale doctrine
The old 64 Grub / 48 Fit figures are retired as product targets. They remain historical commissioning checkpoints only.

Short-term structured-content objective:
- 2,500 commissioned Grub recipe/food objects.
- 2,500 commissioned Fit exercise/movement objects.

Long-term minimum content universe:
- 10,000+ quality-controlled Grub objects.
- 10,000+ quality-controlled Fit objects.

These are quality objectives, not vanity row counts. Every object must remain useful, meaningfully distinct, structured, provenance-aware and eligible for quarantine/withdrawal when validation fails.

## Factory KPI
Track both inventory and conversion:

Grub: idea/demand -> authored -> schema-valid -> nutrition/domain-valid -> reviewed -> published -> production-served -> launch-ready -> simulated/monitored.

Fit: idea/demand -> authored -> schema-valid -> domain-valid -> visual-produced -> visual-QA -> reviewed -> published -> production-served -> launch-ready -> simulated/monitored.

At scale, independent batches should occupy multiple stages simultaneously. A failed or uncertain object is quarantined without blocking unrelated clean content.

## Current industrial acceleration
PR #72 establishes a single-window 224-object Grub industrial authoring universe and 224-object Fit movement/variation universe, in addition to the existing 32+32 structured commissioning catalogue. The 448 industrial objects enter structured storage as quarantined drafts. They do not count as nutrition-valid, visual-QA, reviewed, published or production-served merely because they exist.

The quality gate rejects duplicate IDs, duplicate Grub titles, exact recipe fingerprints, exact Fit fingerprints, missing recipe safety/storage/substitution structure, incomplete Fit instruction/safety/regression/progression/limitation structure, and volume-based promotion. A duplicate-content defect in the first generated snack set was caught by CI; the catalogue was corrected with materially distinct snack variation ingredients/instructions rather than weakening the duplicate gate.

## Operating rule
Industrialise the conveyor belt without lowering the bar:

AUTHOR -> VALIDATE -> REVIEW -> PUBLISH -> SERVE -> SIMULATE -> BREAK -> FIX -> IMPROVE.

The member runtime must progressively increase structured-serving share and drive legacy V4 fallback toward retirement.
