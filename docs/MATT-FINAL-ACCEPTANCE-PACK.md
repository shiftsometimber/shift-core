# Matt Final Acceptance Pack — V1

Do not run this until the release war-room marks the automated prerequisites READY. It is intentionally one short human session.

## 1. Email verification — target 3 minutes
1. Open the supplied fresh Shift registration URL/account details.
2. Register with the designated real commissioning inbox.
3. Open the Shift verification email.
4. Tap the genuine verification link once.
5. Return to Shift and log in.
6. Confirm the Welcome email arrived.
**Expected:** verified login succeeds; no replay/bypass; Welcome received.

## 2. Password recovery — target 3 minutes
1. From member login choose Forgot password.
2. Enter the designated commissioning inbox.
3. Open the genuine reset email.
4. Tap the genuine reset link.
5. Set the supplied commissioning password and tell the war-room DONE.
**Automation then owns:** login -> authenticated password change -> logout -> final login -> retained evidence.

## 3. Grub launch-cohort editorial decisions
Use the generated launch-cohort review surface only. Decisions are PASS / FIX / REJECT against immutable family digests, ordered by recipes unlocked. PASS propagates only to descendants whose hashes remain inside that approved digest.

## 4. Fit launch-cohort visual decisions
Use the generated visual review surface only. For each canonical movement: verify anatomy/start-action/equipment/instruction agreement/safety/mobile legibility, then PASS / FIX / REJECT. PASS propagates only to already-green protocol descendants bound to that canonical movement.

## 5. Final physical-device hostile acceptance — target <= 20 minutes
### iPhone Safari
Home -> Register/Login -> My Shift -> Today -> Grub -> Fit -> Progress -> Progress Picture -> My Plans -> Shift AI -> logout/login. Check: no horizontal scroll; nav opens/closes; cookie UI never blocks intended controls; forms/selects feel native-premium rather than broken/default; loading/empty/error states intelligible; back/forward works; keyboard does not obscure critical controls.

Record only failures with page/action/screenshot. If all pass, mark FINAL DEVICE ACCEPTANCE PASS.
