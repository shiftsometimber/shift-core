# Operations, economics and acquisition preparation
28 September 2026. Prepared internal materials; no spending, messages or campaigns sent.

## Capacity worksheet
Owner fills: named primary operator; backup; staffed days/hours; weekly available minutes B; observed triage time; expected requests q per member per week; mean handling minutes m; fixed weekly administration A.
For n members, expected load = n*q*m + A. Maximum supported cohort = floor((B-A)/(q*m)) when inputs positive; unknown inputs mean capacity unproven.
Stress case uses actual observed high-support q and m. Count follow-up and escalation time, not only first reply. Do not recruit above measured capacity or publish response-time promises before staffing supports them.
Daily working-day queue review: access problems, unresolved saved-data failures, pending account-deletion tasks, supplier handoffs. Record received, assigned, next action, resolved and evidence. Account-deletion receipt is not completion.
Clinical and urgent queries follow existing approved routes; no new clinical service promised.

## Economics input and calculation worksheet
| Input | Required evidence |
|---|---|
| R: net retained revenue per transaction/member period | Actual partner statement/contract; record period and deductions already made |
| V: remaining variable fulfilment cost | Actual un-deducted kit, shipping, dispensing/review costs where applicable |
| P: payment cost | Actual fee schedule, refund and chargeback treatment |
| M: staff minutes | Observed normal/high-support time |
| H: staff hourly cost | Actual fully costed rate |
| T: variable platform cost | Actual usage allocation |
| C: acquisition cost | Actual channel spend/time basis, once only |
Contribution before acquisition = R - V - P - M*H/60 - T.
Contribution after acquisition = previous result - C.
Free-member support cost = M*H/60 + T (+ any applicable payment/other variable cost); assume no future purchase.
Compare normal and high-support cases using actual inputs; show blank/not supplied until known. Setup/fixed costs are separate; positive variable contribution alone is not whole-business profitability.
No prices, supplier terms, forecasts or positive margins invented.
