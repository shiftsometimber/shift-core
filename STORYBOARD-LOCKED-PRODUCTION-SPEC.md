## Shift Me authority
The CSS/mannequin character is rejected as a member-facing result.

Required journey:
PHOTO -> authenticated /v1/shift-me/render -> recognisable same-member generated Shift Me -> creator controls -> regenerate same identity with obvious selected trait change -> SAVE -> persistent member Shift Me -> Timber Mill -> Fit.

Every offered creator control must visibly work. Current supported backend controls include build, body shape, face, hair, hairline, facial hair, skin, eyes, glasses, top, bottoms and accessory. A control that does not alter the generated output must not ship.

Identity lock: never beautify, muscularise, de-age or silently slim the member. Deliberate member-selected trait changes may alter only that trait while preserving identity.

## Release gate
Storyboard is an acceptance test, not inspiration. Fail for visual drift, poor imagery, wrong casting, wrong logo size/placement, legacy branding, fake controls, mannequin/placeholders, broken responsive layout, developer/RC copy or material storyboard deviation.
