# Contact presentation

Next visual preview following completion of the four pages and My Timber Menu in Review Images Together. Contact receives the new Work with us enquiry links. Its existing side heading was squeezed across three short lines; present the original copy and form with the approved font, clearer spacing and a single-column contact heading.

Preserve every original field, option, required flag, input name, label, link, telephone number, safety notice, shared header/footer and production contact handler. Source comes from the current Core Contact response on each request. Only scoped CSS and presentation markers are added in production.

Preview has zero public routes and is noindex. Its submit button is disabled, a capture listener prevents form submission, and non-GET/HEAD requests and private APIs are rejected. Browser checks use empty fields and inspect form structure/category selection; never send a message or claim delivery acceptance. Production form submission remains outside this design change.
