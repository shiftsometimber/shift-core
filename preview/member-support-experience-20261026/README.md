# My Timber private member-support example

Prepared under Matt's 26 October 2026 member-support takeover brief.

This folder contains a deterministic, offline product example for review. It has no production API, registration, analytics, notification or messaging calls. Its two fictional accounts are stored in browser-local example keys. Real member data must not be imported into it.

The ordinary first visit provides a useful meal, shopping shortcut, small plan or manageable movement example before fictional joining. Feedback changes timing, effort or approach. Counts are derived from explicit fictional feedback, and one answered offer cannot inflate its count. The day-thirty control loads clearly fictional history, not an elapsed-time or production claim. The five graph histories reuse the previously agreed invented records.
